# Tndrr AI/ML Internship Assignment

This repository contains my solutions for the Tndrr AI/ML internship assignment.

## Tasks

### Task 1: Fine-Tuning with LoRA
Fine-tuned Qwen2.5-0.5B-Instruct for emotion classification using LoRA and evaluated its performance against the baseline.

Folder: `task1-finetuning/`

### Task 2: Retrieval-Augmented Generation (RAG)
Built a RAG pipeline from scratch using the NIST AI Risk Management Framework document, embeddings, NumPy cosine similarity, and an LLM for answer generation.

Folder: `task2-rag/`

### Task 3: Local LLM Optimization
Compared FP16 and 4-bit quantization, measured inference speed and memory usage, and estimated serving capacity.

Folder: `task3-local-llm/`

## Repository Structure

- `task1-finetuning/` – Fine-tuning notebook, LoRA adapter, and evaluation metrics.
- `task2-rag/` – Source document, preprocessing, retrieval, evaluation, and embeddings.
- `task3-local-llm/` – Optimization notebook, benchmarks, and quality results.

## Technologies

Python, PyTorch, Hugging Face Transformers, PEFT, LoRA, FastEmbed, NumPy, Gemini API, and BitsAndBytes.
